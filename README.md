# المساعد المؤسسي الذكي

نظام يجيب عن أسئلة الموظفين من مستندات الشركة وقواعد بياناتها، مع ذكر المصدر وإظهار الأدوات المستخدمة.

## المشكلة

المعرفة المؤسسية موزّعة بين مستندات نصية (سياسات، لوائح) وبيانات مهيكلة (أنظمة الموارد البشرية). البحث بالكلمات المفتاحية يفشل حين تختلف صياغة السؤال، والنماذج اللغوية العامة لا تعرف بيانات الشركة وقد تخترع إجابات.

## الحل

وكيل ذكي يختار الأداة المناسبة لكل سؤال:

| نوع السؤال | الأداة | المثال |
|---|---|---|
| سياسات وإجراءات | بحث دلالي في المستندات | "ما شروط العمل عن بعد؟" |
| بيانات موظف | استعلام SQL | "كم رصيد إجازة فلان؟" |
| إجماليات ومقارنات | تجميع على كامل البيانات | "كم إجمالي البدلات؟" |

## المعمارية



الفصل بين الطبقات يسمح باستبدال الواجهة (جوال، Teams) دون تعديل المنطق.

## التقنيات

| المكوّن | التقنية | سبب الاختيار |
|---|---|---|
| الخادم | FastAPI | توثيق تفاعلي مولَّد من الكود، تحقّق تلقائي بـ Pydantic |
| الواجهة | Streamlit | سرعة الوصول لنموذج قابل للعرض |
| النموذج اللغوي | Groq (gpt-oss-120b) | واجهة متوافقة مع OpenAI — تبديل المزوّد بسطرين |
| Embeddings | multilingual-e5-base | نموذج retrieval، يعمل محلياً فلا تغادر المستندات الشبكة |
| قاعدة المتجهات | ChromaDB | تخزين دائم مع metadata وفلترة مدمجة |
| البيانات المهيكلة | SQLite | استعلامات دقيقة بلا خادم؛ المسار لـ PostgreSQL مباشر |
| المستندات | PyMuPDF, python-docx, openpyxl | دعم PDF وWord وExcel |

## الميزات

- رفع PDF وWord وExcel ومعالجتها تلقائياً
- تقسيم Word حسب العناوين، وExcel صفاً صفاً
- قراءة نتائج معادلات Excel لا نصها
- منع تكرار المستندات ببصمة المحتوى
- استشهاد بالملف والقسم لكل إجابة
- إظهار الأدوات التي استخدمها الوكيل
- حماية من prompt injection والطلبات واسعة النطاق
- تسجيل الأحداث مع الزمن وعدد الرموز المستهلكة

## التشغيل

```bash
git clone https://github.com/rakan1333/enterprise-ai-assistant.git
cd enterprise-ai-assistant

pip install -r requirements.txt

cp .env.example .env
# ضع مفتاح Groq في .env

python build_db.py          # قاعدة بيانات تجريبية

uvicorn api:app --reload    # نافذة 1
streamlit run app.py        # نافذة 2
```

التوثيق التفاعلي: `http://localhost:8000/docs`
