\# Enterprise AI Knowledge Assistant



مساعد ذكي يجيب عن أسئلة الموظفين من مستندات الشركة، مع ذكر المصدر لكل إجابة.



\## المشكلة



المعرفة المؤسسية موزّعة على مئات المستندات. البحث بالكلمات المفتاحية يفشل حين تختلف صياغة السؤال عن نص المستند، والنماذج اللغوية العامة لا تعرف شيئاً عن سياسات الشركة — وقد تخترع إجابات.



\## الحل



نظام RAG (Retrieval-Augmented Generation) يبحث دلالياً في المستندات، ويعطي النموذج المقاطع ذات الصلة فقط، ويلزمه بالإجابة منها دون سواها.



\## الميزات



\- رفع مستندات PDF ومعالجتها تلقائياً

\- بحث دلالي يفهم المعنى لا الكلمات

\- كل إجابة مرفقة بالملف ورقم الصفحة

\- رفض الإجابة حين لا تحتوي المستندات عليها

\- منع تكرار المستندات عبر بصمة المحتوى

\- دعم العربية والإنجليزية



\## التقنيات



| المكوّن | التقنية | سبب الاختيار |

|---|---|---|

| الواجهة | Streamlit | سرعة الوصول لنموذج قابل للعرض |

| النموذج اللغوي | Groq (gpt-oss-120b) | واجهة متوافقة مع OpenAI، سرعة عالية |

| Embeddings | paraphrase-multilingual-MiniLM | محلي بالكامل — المستندات لا تغادر الشبكة |

| قاعدة المتجهات | ChromaDB | تخزين دائم مع metadata وفلترة مدمجة |

| معالجة PDF | PyMuPDF | الأسرع والأدق في استخراج النص |

| التقطيع | LangChain TextSplitter | تقطيع يحترم حدود الفقرات والجمل |



\## التشغيل



```bash

git clone https://github.com/rakan1333/enterprise-ai-assistant.git

cd enterprise-ai-assistant



pip install -r requirements.txt



cp .env.example .env

\# ضع مفتاح Groq في .env



streamlit run app.py

```
